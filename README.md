# TextClipper

**Версія MVP: 1.0.0.** [Результати перевірки](TESTING.md). Інструкція створення APK — нижче. Згенеровані APK, локальні логи, SDK-конфігурація та ключі підпису виключені з Git.

Незалежний локальний Android-застосунок для текстових кліпів. Український UI, Android 8.0+ (API 26), Kotlin, Compose Material 3, Navigation Compose, Room/SQLite FTS4. Застосунок не має дозволу INTERNET і не залежить від ForwardApp або LocalBookmarks.

## Можливості

- Створення, редагування, читання, копіювання, поширення та видалення кліпів із підтвердженням.
- Захоплення через Android Share (`ACTION_SEND`, `text/plain`), меню виділеного тексту (`ACTION_PROCESS_TEXT`) та явну кнопку буфера обміну.
- Канонічний Markdown без перетворення вмісту під час запису. Локальне відображення заголовків, цитат, списків, bold/italic, посилань, inline/fenced/indented code. Код зберігає відступи й має горизонтальне прокручування.
- Unicode-хештеги поза кодом і URL, ручні теги, пікер із пошуком та створенням тегів, fuzzy matching українською й англійською.
- Інтерактивна хмара тегів із кількістю кліпів, AND-фільтрами та перейменуванням/об’єднанням тегів. Утримуйте тег, щоб перейменувати.
- Пошук тегів через нормалізований ключ, заголовків і тексту через FTS4 `unicode61`. FTS використовує безпечні токени з prefix matching. Два режими: єдиний список без дублікатів або три групи з лічильниками.
- Рейтинг 0–5. Усі запити списків використовують `rating DESC, createdAt DESC, id DESC`. Зміна `updatedAt` не впливає на порядок.
- Системна, світла й темна теми; збереження налаштувань; статистика бібліотеки.
- Атомарні дискові чернетки, відновлення після знищення процесу, підтвердження виходу з незбереженого редактора. Чернетки доступні над списком кліпів; новий Share створює окрему чернетку.

## Архітектура

Один модуль `app`, без DI-фреймворку й окремих domain-модулів:

- `Database.kt`: Room-сутності, DAO, FTS4, реактивна проєкція призначень тегів, схема БД.
- `Repository.kt`: транзакції збереження, синхронізація джерел тегів, SQL пошуку, об’єднання тегів. `MarkdownDocument` задає простий формат для майбутнього імпорту/експорту.
- `State.kt`: `AppModel` і `EditorModel`, Flow/Coroutines, локальні налаштування та `DraftStore` на `AtomicFile`.
- `TextTools.kt`: чисті функції нормалізації, витягування тегів, fuzzy matching, FTS-токенізації та сортування.
- `Markdown.kt`: локальний парсер блоків/inline-форматування та Compose-відображення.
- `MainActivity.kt`: приймання Android intents; `Ui.kt`: Navigation Compose і mobile-first екрани.

### Джерела тегів

`#vet`, `vet`, `VET` мають ключ `vet` (Unicode NFKC + lowercase із `Locale.ROOT`). Унікальний індекс не допускає дублювання. Читабельна назва зберігається окремо.

Зв’язок `ClipTag` має незалежні `manualAssigned` та `textDetected`. Зникнення хештегу прибирає лише автоматичне джерело. Ручне джерело зберігається. В редакторі ручний тег можна зняти; якщо він залишається в тексті, автоматичний chip показується окремо та також може бути прихований.

Приховані автоматичні теги записуються в `suppressed_tags`, щоб вони не поверталися при відкритті редактора чи збереженні без зміни тексту. Виключення скидаються лише після зміни Markdown. Остаточна синхронізація виконується транзакційно при збереженні. Текст із хештегами залишається незмінним.

### База та міграції

Початкова версія схеми — 1; JSON Room-схеми зберігається в `app/schemas`. Зв’язки мають зовнішні ключі з каскадним видаленням, теги — унікальний нормалізований ключ. Індекс списку відповідає полям сортування. FTS external-content синхронізується тригерами Room.

При наступній зміні схеми потрібно збільшити версію, додати явну `Migration` до `databaseBuilder` та тест переходу з JSON попередньої схеми. Destructive migration не ввімкнено: несумісний апгрейд не повинен мовчки знищувати бібліотеку. Для початкової версії попередніх схем для міграції ще немає.

## Збірка та встановлення

Потрібні JDK 17, Android SDK Platform 36 та Android Build Tools. Gradle Wrapper 8.13 включено. Створіть `local.properties` із `sdk.dir=/шлях/до/Android/Sdk` або задайте `ANDROID_HOME`.

```sh
cd textclipper
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Або відкрийте каталог `textclipper` в Android Studio та запустіть `app` на пристрої Android 8.0+.

Версії залежностей зафіксовані у Gradle. Через недоступність мережі використані сумісні стабільні версії з локального кешу, а не найновіші випуски всіх бібліотек. Оновлювати Compose слід узгоджено. Kotlin 2.4.10 попереджає про майбутнє припинення підтримки Gradle 8.13 у Kotlin 2.5; поточна пара підтримується.

## Тести

```sh
./gradlew :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
./gradlew :app:lintDebug
```

`TextToolsTest` перевіряє Unicode-нормалізацію, виключення Markdown/URL/коду, дедуплікацію, fuzzy ranking, FTS-токенізацію, стабільне сортування та довгий Markdown.

`RepositoryTest` використовує Robolectric з Android API 34 та native SQLite: CRUD, FTS кирилицею, ручні/автоматичні прив’язки, AND-фільтри, обидва джерела результатів, перейменування зі злиттям, рейтинг, збереження `createdAt`, перезапуск БД, дискові чернетки та приймання Share/Process Text.

`DatabaseTest` в `androidTest` перевіряє DAO/репозиторій на реальному Android SQLite. Результати виконаних перевірок і сценарії ручного тестування — у [TESTING.md](TESTING.md).

## Межі MVP

- Локальний Markdown-рендерер підтримує перелічені базові конструкції, але не є повною реалізацією CommonMark: немає таблиць, HTML, зображень, складного вкладеного форматування та reference links. Оригінальний текст завжди зберігається повністю.
- Пошук кліпів — за словами й початком слів, без морфології та виправлення помилок; fuzzy matching застосовується до пікера й хмари тегів.
- Бібліотека та чернетки зберігаються у приватному каталозі застосунку. Експорт/імпорт і резервні копії ще не реалізовані; Android Auto Backup вимкнено. Видалення застосунку видаляє локальні дані.
- Немає синхронізації, AI, сервера, авторизації, вебскрейпінгу, перекладу, фонового читання буфера чи WYSIWYG.
- Запуск зовнішніх URL залежить від установленого обробника посилань; завантаження URL у самому TextClipper не виконується.
