# Перевірка TextClipper

## Результати виконання

- `assembleDebug`: успішно, готовий APK у `dist/TextClipper-1.0.0-debug.apk`.
- Компіляція Kotlin/Java, Room KSP і `compileDebugAndroidTestKotlin`: успішно.
- JUnit + Robolectric: **16 тестів, 0 помилок**, API 34, native SQLite. Серед них запуск MainActivity, повторний Share/Process Text та пересоздання Activity зі збереженим станом.
- APK Signature Scheme v2: підпис перевірено `apksigner verify --verbose`.
- Manifest перевірено `aapt2 dump permissions`: дозволу INTERNET немає.
- Lint: не виконано через відсутню залежність і недоступну мережу.
- Пристрій/емулятор: не перевірено через заборону запуску ADB у середовищі.

Локальні логи перевірки збережені в `verification/`, APK та його контрольна сума — у `dist/`. Ці згенеровані файли виключені з Git; APK можна відтворити за інструкцією у README.

## Ручна перевірка на телефоні

1. Встановити APK на Android 8.0+; увімкнути режим польоту.
2. Створити кліп без заголовка: `Привіт #ветеринарія #vet`; додати вручну `VET`, рейтинг 5. Перевірити одну категорію vet.
3. Відкрити кліп, змінити всі поля, прибрати `#vet` із тексту й зберегти. Ручний vet повинен залишитися.
4. Додати лише автоматичний `#android`, зберегти, прибрати його з тексту, зберегти. Зв’язок android має зникнути.
5. Приховати автоматичний тег через chip, зберегти й відкрити редактор знову. Він не повинен повертатися. Після зміни тексту має відбутися повторне розпізнавання.
6. Додати Markdown із заголовками, цитатами, списками, bold/italic, посиланнями, inline code та fenced code; вставити довгу статтю. Звірити режим читання й оригінал у редакторі, перевірити відступи коду.
7. У пікері знайти тег із невеликою помилкою, призначити кілька тегів і створити новий. У вкладці тегів перевірити AND-фільтр, очищення та довге натискання для перейменування.
8. Знайти кліп за тегом, словом заголовка та кириличним словом із середини тексту. Перемкнути єдиний і групований режими; перевірити лічильники й порядок.
9. Створити кілька кліпів з рейтингами 0, 1 і 5. Відредагувати старий кліп без зміни рейтингу: createdAt має зберегтися, нове редагування не переносить його вгору.
10. У сторонньому застосунку виділити текст → «Поділитися» → TextClipper → «Зберегти». Повторити двічі з різними текстами, у тому числі коли TextClipper закритий. Перевірити також PROCESS_TEXT там, де він підтримується.
11. Скопіювати текст і натиснути «Із буфера». Перевірити копіювання та поширення з контекстного меню кліпу.
12. Ввести незбережений довгий текст, повернути телефон, перейти у фон і назад. Через «Назад» та нижню вкладку перевірити діалог: продовження, збереження чернетки, відкидання. Після перезапуску відкрити чернетку зі списку.
13. Встановити світлу/темну/системну тему та режим пошуку, перезапустити застосунок. Перевірити налаштування, статистику, збережені кліпи та пошук.
14. Видалити кліп із підтвердженням. Переконатися, що він зник із результатів FTS і лічильники тегів оновилися.

Системний Share-sheet, поведінка різних зовнішніх редакторів, візуальне компонування на фізичному екрані та клавіатура потребують перевірки на пристрої. У поточному середовищі ADB не може створити локальний сокет (`Operation not permitted`), тому встановлення й інструментальні тести на пристрої не виконані.

## Середовище виконання

JDK 17, SDK Platform 36, Gradle 8.13. Інтернет недоступний, використано локальний кеш залежностей. Системний Gradle не може створювати сокети координації; для перевірки використано окрему тимчасову копію дистрибутива в `/tmp` з вимкненою мережевою координацією файлових блокувань та одним процесом збірки. Java-компілятор запускався в процесі Gradle. Продуктовий код і Gradle Wrapper у проєкті цих змін не містять.

Тестові класи компілювалися Gradle та запускалися JUnitCore у звичайній JVM із тими самими runtime-залежностями й Robolectric API 34/native SQLite. Це дозволяє виконати тести без TCP-з’єднання, яке потрібне стандартному Gradle test worker. Для стандартного середовища достатньо `./gradlew :app:testDebugUnitTest`.

Lint було запущено, але він недоступний: `com.android.tools.lint:lint-gradle:31.13.0` відсутній у кеші; завантаження заблоковане відсутністю мережі. Статус lint не вважається успішним.
